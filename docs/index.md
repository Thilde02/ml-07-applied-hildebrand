## Phase 5. Custom Project

For Phase 5, I applied the skills from the module to create a custom investigation in `ml_07_hildebrand.ipynb`.

The custom notebook builds on the example project but focuses on investigating the model's behavior through feature variation and visualization.

### Basis and Model

I started with the model and analysis provided by the example project.

Rather than treating the model as a black box that produces a single prediction, I used the custom notebook to investigate how predictions changed when selected input features were varied.

The goal was to understand the model's behavior and identify which input features appeared to have the greatest effect on its predictions.

### Investigation Approach

I investigated the model by varying selected features and examining the resulting predictions.

The analysis included a two-feature prediction grid. Two features were varied together across a range of values while the other model inputs were held constant.

This approach allowed me to examine the model's prediction surface rather than looking at only one prediction at a time.

The main question I was investigating was:

> How does the model's prediction change when important features are changed, and are there combinations of feature values where the model's behavior changes noticeably?

### Findings: Feature Sensitivity

The prediction-grid visualization provided a useful way to see how the model responded to changes in the selected features.

The heatmap showed regions where predictions were relatively higher or lower and demonstrated that the model's output was not constant across the feature space.

The strongest changes in the visualization indicate areas where the selected features have a greater effect on the model's predictions.

This visualization was especially useful because it made patterns in the model's behavior easier to see than individual numerical predictions.

### Findings: Prediction Grid

The two-feature prediction grid was one of the main custom additions to the project.

By varying two features simultaneously, I was able to visualize the model's response across a range of possible input combinations.

The resulting heatmap provides an analyst-oriented view of the model and helps identify areas where predictions change gradually as well as areas where the prediction surface changes more noticeably.

This type of analysis can be useful when trying to understand whether a model behaves consistently across its input space.

### Findings: Section 5 Analysis

Section 5 extended the custom investigation beyond the basic example analysis.

I used the results from the earlier sections to further examine the model and interpret the patterns shown by the predictions and visualizations.

The combination of numerical results and visual analysis helped me understand that evaluating a model is not only about whether it produces a prediction. It is also important to investigate how the prediction changes when the inputs change.

### Summary

This custom investigation helped me better understand how a trained model responds to changes in its input features.

The prediction grid and heatmap were particularly useful because they transformed individual predictions into a visual representation of model behavior.

The analysis also showed the value of examining a model across a range of inputs rather than relying on a single example.

If I expanded this project further, I would investigate additional feature combinations, compare different model configurations, and test more edge cases to determine whether the observed patterns remain consistent.

The approach used in this project could be applied to other machine-learning problems where analysts need to understand how input features influence predictions and where a visual representation of the prediction surface can reveal patterns that are difficult to identify from individual predictions alone.
